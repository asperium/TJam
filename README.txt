TJam -Lightweight Clipboard Manager & Text Expander

OVERVIEW:
TJam is a fast, lightweight clipboard history utility and snippet expander designed for Windows. It runs quietly, maintains a searchable history of your clipboard items, and allows you to instantly expand custom text shortcuts using the mandatory '!' prefix.

FEATURES:
- Real-time clipboard history logging (up to 50 items)
- Quick search bar to instantly filter past clips
- Custom text shortcut expansion (e.g., typing a registered trigger expands to your saved phrase)
- Right-click context menu support to add custom items or manage shortcuts
- Clean, minimalist interface with standard Windows taskbar integration

SYSTEM REQUIREMENTS:
- Windows 10 or Windows 11 (64-bit)

GETTING STARTED:
1. Launch TJam.exe to open the main dashboard.
2. Copy any text normally; it will automatically populate in your history list.
3. Select any item in the list and click "Add shortcut" to bind a custom '!' trigger to it.
